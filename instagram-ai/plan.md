# Instagram «ИИ в маркетинге»: шапка профиля и 30 рилс

Как пользоваться:
1. Записываешь голос по тексту из карточки на телефон и кладёшь файл в папку ролика (`reels/ai-NN-.../source/voice.m4a`), туда же скриншоты и записи экрана, если они нужны.
2. Копируешь задачу из карточки в Claude Code.
3. Claude Code собирает первые 3 секунды, показывает их тебе и после твоего «ок» монтирует весь ролик.

В квадратных скобках `[ ]` то, что нужно заменить своим: цифры, ответы ИИ, названия. Цифры не выдумываем: только то, что было на самом деле.

---

## Шапка профиля

**Имя** (это поле ищется в поиске Instagram):
`[Имя] | ИИ в маркетинге`

**Описание, вариант 1 (рекомендую):**
```
ИИ делает работу маркетолога, а я показываю как
▪️ Фишки и промпты каждый день
▪️ Эксперименты на реальных деньгах
👇 Промпт для контент-плана бесплатно
```

**Вариант 2:**
```
Маркетинг с ИИ без воды
За 10 минут делаю то, на что уходил день
👇 Забирай 30 моих промптов
```

**Вариант 3** (если ведёшь свой бизнес):
```
Веду бизнес с ИИ вместо команды
Показываю всё: промпты, цифры, ошибки
👇 С чего начать, бесплатно
```

**Ссылка:** Telegram-канал или страница с бесплатным промптом. Это тот же подарок, что раздаёшь по кодовым словам.

**Актуальное (круги под шапкой):** Старт · Промпты · Эксперимент · Обо мне · Отзывы. Обложки в цветах аккаунта: графит и лайм.

**Аватар:** твоё настоящее лицо крупно, однотонный светлый фон, улыбка. Не генерировать.

**Закрепить 3 рилс:** №1 (кто я), №2 (лучшая польза), №24 (подарок по слову «ПЛАН»).

## Общие правила монтажа (для Claude Code)

```
Общие правила для всех роликов аккаунта @твой_ник (ИИ в маркетинге):

- Формат 1080×1920, 30 fps, 20–35 секунд. Собирай в HyperFrames (скиллы hyperframes, hyperframes-cli,
  готовые блоки — hyperframes-registry). Папка ролика: reels/ai-NN-<тема>/. GSAP — из npm, не с CDN.
- Исходники в reels/ai-NN-<тема>/source/: voice.m4a (моя озвучка), иногда face.mp4 (я в кадре),
  скриншоты и записи экрана. Исходники не меняй и не перезаписывай.
- Ролик анимационный: всё, о чём я говорю, показано движением (окна чата, таблицы, счётчики,
  карточки), а не просто написано словами.
- Цвета: фон графит #111114, текст белый #F5F5F2, акцент лайм #C8FF3D (максимум 1–2 элемента
  на кадр), второстепенный серый #8A8A93, ошибки — красный #FF4D4D. Интерфейсы (чат, профиль,
  таблица, директ) — тёмные карточки #1C1C21, радиус 28, обводка 1 px #2A2A31.
- Шрифты из library/fonts: заголовки Inter Tight 800, текст Inter 400/500, промпты и метки —
  JetBrains Mono 500.
- Звуки из library/sfx: key — печать текста, pop — появление, whoosh — переходы, tick — счётчики,
  shimmer — результат, impact — только удар хука. Музыка тихо под голосом (на 18–22 dB тише голоса),
  можно library/music/calm_pad.wav. Если выбираешь музыку по описанию — так и скажи.
- Из DESIGN.md раздел 0 действует и здесь: ничего гигантского (хук 54–72 px), заголовки чуть ниже
  середины кадра, без тряски кадра, человека из фона не вырезать, без затемнений и градиентов
  поверх видео, читаемость — мягкой тенью.
- Субтитры по моему голосу (распознай речь): белые, Inter 400, 44 px, не больше 2 слов, без точек
  и запятых, без плашек.
- Хук: уже на 0,3 с есть движение и текст. Внизу всегда маленькая плашка @твой_ник.
- Финал 1,5 с: «Подпишись — завтра …» и кодовое слово, если оно есть в задаче.
- Порядок работы: сначала собери первые 3 секунды, покажи мне 3 кадра и жди «ок». Потом весь
  ролик. Перед словом «готово» посмотри кадры из рендера и замерь громкость (цель около −14 LUFS).
- Видео в git не клади.
```
