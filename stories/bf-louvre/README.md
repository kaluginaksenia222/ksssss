# Сторис Black Friday — ЖК «Лувр» (утверждённый образец)

Эталон — квартира 1 (`?id=1`). Все следующие квартиры делаются ровно так же.

**Правила образца**
- Фон — тёмный бетон, красные ленты SALE крест-накрест сверху и снизу.
- Заголовок: «ЖК «ЛУВР»» мелко, «BLACK» красным + «FRIDAY» белым.
- Белая карточка: «2-К КВАРТИРА №» / «WHITE BOX · ДОМ СДАН» слева, площадь и «ЭТАЖ N» справа.
- Планировка — из файла заказчика, без надписей улиц, фон чисто белый, крупно по центру карточки.
- Красный билет — только процент скидки («−11%»), без суммы выгоды.
- Цены: старая зачёркнута красной линией, новая = старая − скидка, округление до рубля.
- Данные с сайта louvre-e.ru: комнатность, площадь, этаж, номер, цена.
- Логотип «Высоцкий Девелопмент» белым внизу. Шрифт Onest, всё капсом.

**Как добавить квартиру**
1. Планировка: `python3 -I scripts/prep_plan.py <файл> <id>` (лишние надписи — стереть заранее).
2. Данные: новая запись в `data/flats.js` (с `badge: "−11%"`).
3. Рендер: `node scripts/render.cjs renders/story-<id>.png <id>` (NODE_PATH=$(npm root -g)).
