# Монтаж хирурга в операционной

Утверждённый заказчиком стиль. Эталон — проект `video/` (композиция `Blepharoplasty`, git-метка `montage-surgeon-or-v1`).
Правила оформления — раздел **0** в `DESIGN.md`. Они главнее всего остального: прочитать перед работой.

## Как выглядит ролик

1. **0–7 с, хук на весь кадр.** Сверху видео: плашка темы, таймкод, полоска подпунктов с бегунком. Через 0,5 с из-под маски выезжают моно-метка «ПАМЯТКА ПАЦИЕНТУ» и белый заголовок в 2 строки (54 px) — под головой. Белые субтитры сразу под ним.
2. **С 7 с до конца, сплит.** Сверху съезжает бежевая панель с точечной сеткой, видео уходит вниз (лицо видно целиком). На панели: плашка темы, метка «01 / 05», по центру — окно-вставка (слегка бежевое, 820 px) с названием раздела. Внутри окна всё появляется **в такт речи**: блоки со скелетон-строками, карточки с иконками, вкладки, календарь, поле с печатью текста, галочки, прогресс-бары. Синие субтитры — на панели под окном.
3. **Внизу весь ролик** — плашка Instagram с ником хирурга (`@dr_kudryakov`).
4. **Звук:** голос (−14…−16 LUFS), тихий свуш на хуке и сменах вставок, щелчки клавиш при печати, тихий «поп» на 2–4 главных появлениях во вставке.

Ничего гигантского, ничего поверх лица, без дублирования текста, без точек в субтитрах. Референс не копировать 1:1.

## Рецепт для нового видео

Рабочая папка — `video/`. Код уже содержит все компоненты; под новое видео меняются данные и содержимое вставок.

1. **Исходник.** Взять видео (например, из релиза GitHub), положить как `video/public/source.mp4`:
   `ffmpeg -i raw.mov -c:v libx264 -crf 18 -pix_fmt yuv420p -c:a aac -b:a 192k -movflags +faststart public/source.mp4`
   Видео в git не добавлять (в `.gitignore`), репозиторий публичный.
2. **Расшифровка.** Hugging Face из окружения недоступен — модель Whisper small берётся из npm:
   `npm pack @skillninja/shortmovie-telop-model-p{0,1,2,3}`, распаковать, склеить `model.bin.part0..3` в `model.bin`, проверить `sha256` по `model.sha256`, рядом положить `config.json`, `tokenizer.json`, `vocabulary.json`, `preprocessor_config.json`. `pip install faster-whisper`.
   `python3 -I scripts/transcribe.py <модель> audio16k.wav transcript.json`
3. **Субтитры.** Поправить в `scripts/pages.py` словарь `fix` (медицинские термины Whisper путает), затем
   `python3 -I scripts/pages.py transcript.json > src/data/transcript.ts`
4. **Разделы.** По расшифровке разбить речь на хук (~7 с) и 3–6 советов. Обновить:
   - `src/timeline.ts` — `SECTIONS` (смена крупности видео) и `SCENES` (старт каждой вставки, `end` = длительность);
   - `src/Root.tsx` — `durationInFrames` = длительность × 30;
   - `src/scenes/Sections.tsx` — текст хука и плашки темы, содержимое окон. Время внутри вставки = момент слова − старт сцены. Под каждое ключевое слово — своё появление;
   - `POP_TIMES` и `TYPING` — под новые появления и печать;
   - ник в `src/Reel.tsx` (`InstagramHandle`), если другой хирург.
5. **Проверка кадрами.** Рендерить отдельные кадры и смотреть: лицо не закрыто, ничего не налезает, размеры мелкие.
   `npx remotion still Blepharoplasty out.png --frame=N --scale=0.35 --browser-executable=/opt/pw-browsers/chromium_headless_shell-1243/chrome-headless-shell-linux64/chrome-headless-shell`
6. **Рендер и громкость** (~10 мин, в фоне):
   `npx remotion render Blepharoplasty out/video.mp4 --browser-executable=<тот же путь> --crf=18`
   `ffmpeg -i out/video.mp4 -c:v copy -af "loudnorm=I=-14:TP=-1.5:LRA=11" -ar 48000 -c:a aac -b:a 192k -movflags +faststart renders/<имя>.mp4`
7. Прислать готовый файл пользователю. Новые правки заказчика записывать в `DESIGN.md`, раздел 0.

## Ресурсы

- Шрифты-замены с кириллицей (Inter Tight / Inter / JetBrains Mono / Great Vibes) — `video/public/fonts`. Фирменные Coolvetica, Helvetica Neue, Gloria Script подставляются первыми, если положить их файлы и подключить в `src/design/fonts.ts`.
- Звуки синтезированы ffmpeg — `video/public/sfx` (whoosh, pop, key, shimmer).
