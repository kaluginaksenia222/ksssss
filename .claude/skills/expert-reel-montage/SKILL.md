# Экспертный монтаж рилс

Утверждённый заказчиком стиль. Эталон — проект `reels/expert-radiesse/`, композиция `ExpertRadiesseV3` (код в `src/v3/`).
Правила оформления — раздел **0** в `DESIGN.md` (главнее всего). Принципы работы — `CLAUDE.md`.

## Как выглядит ролик

1. **Хирург на весь кадр**, в исходном виде: без вырезки из фона, без синих затемнений и градиентов поверх видео, без окон с его лицом.
2. **Сверху** — маленькие стеклянные метки (моноширинный шрифт): «ЭКСПЕРТ · ПЛАСТИЧЕСКАЯ ХИРУРГИЯ · 01 / 05». **Внизу** — плашка Instagram `@dr_kudryakov`.
3. **Сильный хук** (первые ~3 с): кадр влетает из приближения с размытием, вспышка и удар; металлический заголовок-вопрос (64 px, ниже середины), от него мелким шрифтом **эхом** разлетаются перечисления (процедуры) с затухающими следами; на ключевом слове — дрожь кадра и удар.
4. **Металлические заголовки** (Coolvetica, серебристый градиент с бегущим бликом) — 64–80 px, **чуть ниже середины**, на груди. На время заголовка субтитры с теми же словами прячем.
5. **Синие сцены** — короткие, 3–6 с, 2–3 на ролик: открываются кольцом из лица хирурга и закрываются обратно. Внутри — большой круг (прорисовка, вращающийся пунктир, бегущая точка), моно-метка, заголовок, один интерактивный элемент (переключатель или круглая шкала). Без лица хирурга.
6. **На груди поверх видео** — стеклянные элементы: круглые шкалы (кольцо-прогресс, процент в центре, подпись под кругом; **не больше 3 на ролик**), метки-«таблетки». Квадратных карточек нет.
7. **Крупность**: резкая смена по разделам (1.0 ↔ 1.12) и медленный наезд внутри раздела.
8. **Субтитры**: белые, тонкие (Regular), **по 2 слова**, без знаков препинания в конце, без плашек, мягкая тень, ~1110 px от верха.
9. **Звук**: голос (−14…−16 LUFS), блеск + удар на заголовках, свуш на кольце, тихий «поп» на появлениях, щелчок переключателя. Мат за кадром — глушить (громкость 0 на слово).

## Рецепт для нового видео

1. **Новый проект** (один ролик — один проект): скопировать `reels/expert-radiesse/` в `reels/<имя>/` без `node_modules`, `out`, `public/*.mp4`; `npm ci`. Шрифты и звуки — симлинки на `library/`.
2. **Исходник** → `public/source.mp4` (h264, crf 18, faststart). Видео в git не класть.
3. **Расшифровка** — как в скилле `surgeon-or-montage` (Whisper small из npm, `video/scripts/transcribe.py`). Неразборчивые места перераспознать кусочком с `initial_prompt` по теме.
4. **Субтитры** — `scripts/pages_v3.py`: поправить словарь `fix` (термины: SMAS, Радиесс и т. п.) и правила склейки → `src/v3/transcript.ts`.
5. **Сценарий** в `src/v3/ExpertV3.tsx` по таймкодам слов: хук (заголовок + эхо-слова), моменты заголовков, 2–3 синие сцены (`BLUE*`), шкалы и метки на груди, `CAPTION_OFF`, `ZOOMS`, звуки. Время элемента = момент слова. Найти координаты лица хирурга в исходнике (`RING_CENTER`) — по кадру через ffmpeg.
6. **Этапами**: сначала начало (~13 с) → показать → «ок» → дальше.
7. **Проверка кадрами** (`npx remotion still ... --scale=0.25`): лицо не закрыто, ничего не налезает, всё мелкое.
8. **Рендер** (в фоне, ~10–15 мин) и громкость:
   `npx remotion render <Composition> out/full.mp4 --browser-executable=/opt/pw-browsers/chromium_headless_shell-1243/chrome-headless-shell-linux64/chrome-headless-shell --crf=18`
   `ffmpeg -i out/full.mp4 -c:v copy -af "loudnorm=I=-14:TP=-1.5:LRA=11" -ar 48000 -c:a aac -b:a 192k -movflags +faststart renders/<имя>_v1.mp4`
   Замерить громкость и заглушённые места, посмотреть кадры — потом отправлять. Новые версии — с новыми именами.
